# Docker-01 Cloud Backup

Docker-01 Cloud Backup is a private, personal application used by its owner to create backups of data stored in Google Drive.

The application uses Google OAuth to provide read-only access to the owner's Google Drive for the sole purpose of copying files to the owner's private backup storage.

The application is not offered to the public and does not provide services to third parties.

## Data Access

Google Drive data accessed by this application is used solely for personal backup purposes.

The application does not sell, share, or disclose Google user data to third parties.
